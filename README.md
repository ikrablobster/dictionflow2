# DictaFlow

Офлайн-диктовка для Windows на Tauri 2, React и Whisper (whisper.cpp).

## Использование

1. В настройках выберите микрофон и нажмите «Проверить микрофон».
2. Выберите язык и модель. `tiny` и `base` требуют меньше ресурсов, `tiny` — модель по умолчанию; `medium` и `large-v3` требуют значительно больше памяти и времени.
3. Нажмите «Начать диктовку». При первом запуске выбранная модель скачивается с Hugging Face; прогресс отображается в главном окне. Дождитесь «Слушаю…», затем говорите.
4. Нажмите «Остановить», чтобы получить полный текст. При запуске кнопкой результат отображается в приложении и сохраняется в истории.
5. Для вставки в другое приложение удерживайте горячую клавишу. Отпускание завершает запись и запускает распознавание. Пока идёт обработка, оставьте нужное окно активным.

Горячую клавишу можно выбрать из списка или назначить нажатием: Ctrl, Alt, Shift, CapsLock, F1–F12. Esc отменяет назначение; тайм-аут — 10 секунд. Выбирайте клавишу с учётом сочетаний в ваших приложениях.

Предпросмотр показывает последние 12 секунд речи после обработки моделью. Он не является мгновенной потоковой транскрипцией. Итоговая транскрипция включает всю запись. Максимальная длительность записи — 10 минут, затем она автоматически завершается.

Всплывающее окно не получает фокус. На Windows при смене активного окна автоматическая вставка отменяется, результат остаётся в истории. Поля с повышенными правами и защищённые поля могут не принимать эмуляцию ввода.

## Данные и модели

Модели хранятся в `%APPDATA%/DictaFlow/models`, настройки — в `%APPDATA%/DictaFlow/config.json`, история — в `%APPDATA%/DictaFlow/history.sqlite3`.

Модель загружается при первом запуске диктовки с выбранным размером. Для завершённых загрузок используется `ggml-<размер>.bin`, для незавершённых — `.bin.part`. HTTP-ошибки и сбои модели отображаются в интерфейсе. Если ранее был сохранён повреждённый `.bin`, удалите только этот файл при закрытом приложении и повторите загрузку.

Без включённого облачного режима аудио и текст обрабатываются локально. Облачная коррекция в текущей версии настраивается через конфиг и использует OpenAI API; по умолчанию выключена. Офлайн-обработка текста — правила пунктуации, регистра, голосовые команды переноса строк и пользовательский словарь, а не полноценный корректор грамматики. Команда удаления предложения во внешнем приложении не реализована.

## Разработка и проверки

Для полной сборки Windows нужны Node.js 22, Rust stable (MSVC), Visual Studio Build Tools с C++, Windows SDK, CMake и LLVM/Clang для whisper.cpp.

```powershell
npm ci

npm test
npm run build
cargo test --release --manifest-path src-tauri/Cargo.toml
npm run tauri build
```

Установщики: `src-tauri/target/release/bundle/msi` и `src-tauri/target/release/bundle/nsis`.

GitHub Actions запускает тесты интерфейса, тесты Rust и сборку установщиков для PR в `main`, при обновлении `main` и вручную. Артефакт называется `dictaflow-windows`. Основной проверяемый целевой вариант — Windows; автоматической сборки macOS в текущем workflow нет.

## Перед выпуском

Проверить на реальной Windows: значок в трее на светлой и тёмной панели; назначение клавиши несколько раз, Esc и тайм-аут; запись кнопкой; удержание/отпускание хоткея в Блокноте; первый запуск без модели и без сети; повторное нажатие во время обработки; отключение микрофона; смену активного окна; автозапуск после входа в Windows.

Автоматические тесты без оборудования не подтверждают работу конкретного аудиодрайвера, глобального клавиатурного hook и вставки в сторонние приложения.

## Быстрые настройки и диагностика

Для слабого процессора используйте Tiny, конкретный язык и выключенный предпросмотр. Кнопка «Включить быстрые настройки» применяет Tiny и отключает предпросмотр, сохраняя выбранный язык. Существующие настройки автоматически не заменяются. Tiny уступает более крупным моделям по точности. Скорость зависит от процессора и записи; гарантии обработки за 3 секунды нет.

Предпросмотр запускается не раньше четвёртой секунды. При остановке его вычисления отменяются, освобождая движок для итогового текста. Состояние модели переиспользуется между записями. После обработки отображается затраченное время.

Иконка приложения — исходный пользовательский ICO в src-tauri/icons/icon.ico; public/app-icon.ico — его точная копия для интерфейса. Не запускайте генератор старых PNG поверх ICO.

Для измерения без микрофона доступна команда: dictaflow.exe --benchmark input.wav model.bin ru output.json 3. Нужен моно WAV PCM16 16 кГц. Два последовательных распознавания и время загрузки записываются в JSON. Модель должна уже находиться на диске; сетевых загрузок эта команда не выполняет.
